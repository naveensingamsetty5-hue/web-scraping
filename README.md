# Task 1: Web Scraping

## Objective
Collect structured data from a public web page using Python Requests and BeautifulSoup.

## Files
- Python implementation in `src/`
- Dataset/results in `data/` or `outputs/`
- Generated visual(s) in `visuals/`

## How to run
```bash
pip install -r requirements.txt
```

Then run the Python file inside `src/`.
